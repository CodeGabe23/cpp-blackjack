# cpp-blackjack

Project Finished!

My version of blackjack with GUI using Raylib in c++

**How To Build (Linux)**

1) run `git clone https://github.com/CodeGabe23/cpp-blackjack.git`

2) cd to ./build directory and run:

3) `cmake ..`

4) `make`

5) move the executable file 'Blackjack' into root directory so it can access the assets. `mv Blackjack ../`

6) Lastly, cd to root dir `../` and run `./Blackjack` to play.
